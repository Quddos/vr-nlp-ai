### Customization Tips

If you want to modify the page:

1. **Change Colors**: Edit the `:root` variables at the top
2. **Adjust Animations**: Modify `@keyframes` sections
3. **Add More Sections**: Duplicate a `<section>` block and add nav button
4. **Update SVG Diagrams**: Edit the `<svg>` elements directly
5. **Change Content**: Edit text directly in HTML
